# Site Concretos JB

Réplica estática do site no Wix (https://concretosjb.wixsite.com/meusite), pronta para o GitHub Pages.
O layout segue o original: largura fixa de 980px, mesmo cabeçalho, menu com "MAIS", galerias e rodapé.

## Imagens
Todas as imagens já estão na pasta `img/`. O script `baixar-imagens.ps1` não é mais necessário.

## Páginas
- Menu: `index.html`, `fale-conosco.html`, `blocos.html`, `lajes.html`, `balaustres.html`,
  `elementos-vazados.html`, `escadas.html` e, no "MAIS": pingadeiras, bancos, caixas, canaletas, guias,
  institucional, molduras, mourões, ornamentos, pisos, placas, tubos e anéis, vasos.
- Catálogos (abertos pelos botões "Clique para Catálogo..."): `catalogo-*.html`.
- `vantagens.html` (botão "Saiba mais" da página Blocos): no Wix ela mostra a digitalização de um artigo
  de revista. Essa imagem **não** foi copiada; confirme se há autorização para republicá-la.

## Formulários (Fale conosco)
Os dois formulários (orçamento e SAC) usam o serviço gratuito FormSubmit (formsubmit.co).
Na primeira mensagem enviada chega um e-mail de confirmação em concretosjb@concretosjb.com.br;
é só clicar no link de ativação. Depois disso as mensagens chegam direto nesse e-mail.

## Fontes
As fontes do Wix são licenciadas; foram trocadas por equivalentes gratuitas do Google Fonts
(Alfa Slab One no título, Abril Fatface no menu, Lobster nos botões, Jockey One nos formulários).
Cores e tamanhos ficam em `style.css`.
